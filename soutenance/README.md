- `Trame_orale_et_scenario_demo.docx` / `.md` — durées, trame orale, scénario de démonstration minuté, plan B, check-list de la veille, questions probables du jury.
- Régénérer le diaporama : `pip install python-pptx` puis `python3 tools/soutenance/diapos.py soutenance/Soutenance_KHS_Bank_MOM-TECH.pptx`.
- `Recette_maquette_Packet_Tracer.docx` / `.md` — recette de la maquette Packet Tracer : chaque test expliqué (objectif, commande, résultat réel, interprétation), les 11 anomalies trouvées et corrigées, les limites, le PV, les questions du jury et un glossaire de tous les sigles. Journal brut : `docs/10-packet-tracer/07-journal-de-recette.md`.
